### About

Java / Spring Boot 后端工程师，同时深度实践 **AI Agent 驱动的全栈开发**。

日常用 Claude、Codex 等 Agent 协作完成真实业务项目，并持续总结可落地的工程方法：需求精简、约束设计、任务拆分、接口验证与错误沉淀。

目前主要关注：
- Spring Boot + Vue 全栈工程实践
- AI Agent 工作流与 Harness Engineering
- 代码知识图谱工具（CodeGraph）在 Agent 开发中的应用
- 实用工具与效率提升
